# ⚡ SparkyTube

**SparkyTube** is a fast, lightweight, and modern open-source YouTube client built for Android. Enjoy seamless video playback and audio streaming with zero ad interruptions and a clean, user-focused interface.

```

---

## ✨ Features

* 🚫 **Ad-Free Experience:** Watch videos without pre-roll, mid-roll, or banner ads.
* 🎵 **Background Audio:** Keep listening to audio while using other apps or with your screen turned off.
* 📱 **Picture-in-Picture (PiP):** Multitask seamlessly while keeping your video playing in a floating window.
* 🎨 **Modern Material UI:** Clean, intuitive interface designed for smooth navigation and ease of use.
* 🚀 **Fast & Lightweight:** Built for performance with minimal resource consumption.
* 🔒 **Privacy-Focused:** No unnecessary tracking or excessive permissions required.

---

## 🛠️ Tech Stack & Build Requirements

* **Platform:** Android

## 🚀 Getting Started

### Prerequisites

* Android Studio Ladybug (or newer)
* JDK 17+
* Android SDK (API 24 or higher recommended)

### Building from Source

1. **Clone the repository:**
```bash
git clone [https://github.com/sparkynox/SparkyTube.git](https://github.com/sparkynox/SparkyTube.git)
cd SparkyTube

```


2. **Open in Android Studio:**
Open Android Studio and select **Open an Existing Project**, then select the cloned `SparkyTube` directory.
3. **Build the APK:**
Build the project directly using Gradle or via Android Studio UI:
```bash
./gradlew assembleDebug

```
